# Reaction Training Game

Микро-проект на Android для тренировки скорости реакции. Суть проста: жмешь кнопку старта, ждешь случайное время и кликаешь, как только загорятся индикаторы.

Этот проект — учебный полигон для отработки современных стандартов Android-разработки (2024–2026 гг.).

## Технологический стек

* **Язык:** Kotlin (чистый код, работа со списками, лямбды).
* **UI:** XML + Material Design 3.
* **Layout:** ConstraintLayout (использование Chains для плоской иерархии).
* **ViewBinding:** Безопасное взаимодействие с UI без `findViewById`.
* **Архитектура:** Принципы инкапсуляции и управления состоянием (State).

## Текущий функционал

На данный момент реализована базовая механика "светофора":
1.  **Защита от спама:** Кнопка блокируется после нажатия, чтобы исключить наложение таймеров.
2.  **Рандомизация:** Задержка перед сигналом генерируется случайно (от 1 до 3 секунд).
3.  **Визуальный отклик:** Использование цветовых фильтров (`ColorFilter`) для изменения состояния индикаторов без перезагрузки графических ресурсов.

## Планы по развитию

Проект находится в активной разработке. В ближайших планах:
- [ ] **Хронометр:** Точное измерение времени реакции в миллисекундах.
- [ ] **Анти-чит:** Обработка преждевременных нажатий (фальстарт).
- [ ] **High Scores:** Сохранение лучшего результата в локальное хранилище.
- [ ] **Dark Theme:** Полная поддержка темной темы через атрибуты Material 3.
- [ ] **Animation:** Плавные переходы и пульсация кнопок для улучшения UX.
