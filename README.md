# Reaction Training Game
Мини‑игра для тренировки скорости реакции на Android.
Жмёшь старт, ждёшь случайный интервал и как можно быстрее реагируешь, когда «светофор» даёт сигнал.

## Цель проекта
Проект сделан как учебный, чтобы:
- потренироваться в построении простого MVVM‑приложения;
- попрактиковаться с таймерами, обработкой UI‑событий и состоянием;
- отточить работу с XML‑версткой, ViewBinding и Material‑компонентами.

## Технологический стек
Язык: Kotlin.
UI: XML‑разметка, Material Components.
Layout: ConstraintLayout.
Архитектура: MVVM (Fragment + ViewModel).
Связь с разметкой: ViewBinding.

## Игровая механика
### Базовая логика «светофора»:
1. Пользователь нажимает кнопку Start.
2. Кнопка блокируется, запускается таймер со случайной задержкой.
3. Индикаторы «светофора» последовательно меняют состояние и в конце показывают сигнал «ЖМИ».
4. Пользователь кликает по кнопке — игра фиксирует результат (на текущем этапе — визуальный отклик и изменение состояния индикаторов).

### Реализовано:
- защита от спама: нельзя запустить несколько таймеров подряд одним спамом по кнопке;
- случайная задержка перед сигналом;
- смена состояний «светофора» с помощью цветовых фильтров / ресурсов, без тяжёлой перерисовки.

## Архитектура и структура модулей
Упрощённый MVVM:
### UI слой
- Activity/Fragment отвечают за:
- показ экрана игры;
- подписку на состояние ViewModel;
- отображение текущего статуса (ожидание, готовность, результат).

ViewModel
- хранит состояние игры (идёт ожидание, можно ли нажимать, текущий цвет «светофора»);
- управляет запуском/остановкой таймеров;
- эмитит одноразовые события для UI (например, показать «фальстарт»).
